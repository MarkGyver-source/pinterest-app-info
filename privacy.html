Datenschutzerklärung

Stand: August 2026

Diese Erklärung betrifft die Nutzung der Pinterest API im Rahmen eines persönlichen Automatisierungsprojekts von Mark ("Betreiber"), umgesetzt über eine selbst gehostete n8n-Instanz.

Wer verarbeitet welche Daten

Die Anwendung greift ausschließlich auf das eigene Pinterest-Konto des Betreibers zu. Es werden keine Konten, Daten oder Inhalte anderer Personen verarbeitet, gespeichert oder weitergegeben.

Welche Daten verarbeitet werden

  • OAuth-Zugriffstoken zur Authentifizierung gegenüber der Pinterest API
  • Von der Anwendung selbst erzeugte Inhalte (Pin-Titel, Beschreibungen, Bilder)
  • Öffentlich zugängliche Produktinformationen aus Web-Recherchen zur Content-Erstellung

Zweck der Verarbeitung

Die Daten werden ausschließlich zur automatisierten Erstellung und Veröffentlichung von Pins auf dem eigenen Pinterest-Board des Betreibers genutzt.

Weitergabe an Dritte

Es findet keine Weitergabe von Daten an Dritte statt, mit Ausnahme der technisch notwendigen Übermittlung an die Pinterest API selbst sowie an zur Content-Erstellung genutzte KI-Dienste (z. B. zur Text- und Bildgenerierung), soweit dies für die Funktion der Automatisierung erforderlich ist.

Speicherdauer

Zugriffstoken werden nur so lange gespeichert, wie sie für den Betrieb der Automatisierung benötigt werden, und können jederzeit durch Widerruf der Pinterest-App-Berechtigung entzogen werden.

Kontakt

Bei Fragen zu dieser Datenschutzerklärung wende dich bitte an den Betreiber über die auf der Startseite genannten Kanäle.
